## What's Inside

Everything is split cleanly by **content type** first, then by **category**, then by **item name**—so you never open a folder expecting HTML and find only a prompt.

| Folder | Count | Contents | Best For |
| --- | ---: | --- | --- |
| [**`With Code/`**](With%20Code) | **341** | Self-contained `index.html` + `prompt.md` | Instant browser preview, copy-paste HTML, or AI customization |
| [**`Prompt Only/`**](Prompt%20Only) | **16** | Detailed `prompt.md` UI build specs | Generating full React / Tailwind layouts in AI builders |
| [**`Backgrounds/`**](Backgrounds) | **86** | Full-bleed HTML5 `<video>` background embeds | Hero backdrops, landing pages, ambient motion |
| [**`Design MD/`**](Design%20MD) | **86** | Brand `DESIGN.md` design-system specs | Teaching AI agents exact colors, typography, spacing & rules |

> Want a single searchable list of all 529 items? Open [**`CATALOG.md`**](CATALOG.md).

```text
open-ui-vault/
├── With Code/          # 341 items  → <Category>/<Item Name>/index.html + prompt.md
├── Prompt Only/        #  16 items  → <Category>/<Item Name>/prompt.md
├── Backgrounds/        #  86 items  → <Tag>/<Item Name>/index.html
├── Design MD/          #  86 items  → <Category>/<Brand>/DESIGN.md
├── CATALOG.md          # Full searchable index of all 529 items
├── CONTRIBUTING.md     # How to submit new templates, prompts & DESIGN.md files
└── THIRD_PARTY_NOTICES.md
```

## How to Use

### 1. Preview or Copy HTML Templates (`With Code/` & `Backgrounds/`)
Clone the repo and open any `index.html` directly in your browser:

```bash
git clone https://github.com/allanindrajith/open-ui-vault.git
cd open-ui-vault
```

### 2. Use With AI Coding Agents (`Design MD/` & `Prompt Only/`)
Copy any brand's `DESIGN.md` into your project root and prompt **Cursor**, **Claude Code**, **Gemini**, **Antigravity**, **Lovable**, **v0**, or **Bolt**:

```text
Read DESIGN.md in this repo root and build a landing page following its exact
color tokens, typography hierarchy, spacing scale, and component rules.
```
