# Contributing

Contributions of original HTML/CSS/JS templates, AI UI prompts, background embeds, and `DESIGN.md` design-system specifications are welcome!

## Folder Structure

Place new items in the matching top-level folder and category:

```text
With Code/<Category>/<Item Name>/
  index.html
  prompt.md          # optional but recommended

Prompt Only/<Category>/<Item Name>/
  prompt.md

Backgrounds/<Tag>/<Item Name>/
  index.html

Design MD/<Category>/<Brand or System Name>/
  DESIGN.md
```

## Submission Rules

1. **Original or Openly Licensed Work Only**: Only submit content you created yourself or that carries a compatible open-source license (MIT, Apache-2.0, CC0, etc.). Never submit paywalled or proprietary templates.
2. **Self-Contained & Clean**:
   - Use clean placeholder text and open-source fonts (Google Fonts, Fontshare, etc.) instead of proprietary fonts.
   - Avoid hotlinking private or expiring media URLs.
3. **Attribution**: If your PR adapts an open-source resource, include its original license and copyright notice in `THIRD_PARTY_NOTICES.md`.
4. **Naming**: Use clean Title Case for folder names (e.g., `With Code/SaaS/Pricing Grid/index.html`).

## Pull Request Checklist

- [ ] Files are placed in the right top-level folder and category
- [ ] `index.html` opens cleanly in a browser (for `With Code/` and `Backgrounds/`)
- [ ] No API keys, credentials, or paywalled content included
- [ ] Upstream license/attribution added to `THIRD_PARTY_NOTICES.md` if applicable
